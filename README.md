# 🌡️ Conversor de Temperaturas

Uma aplicação web desenvolvida em **Python e Flask** para realizar conversões entre as escalas de temperatura **Celsius, Fahrenheit e Kelvin**.

O projeto possui uma interface simples, organizada e personalizada, permitindo que o usuário escolha a escala de origem, a escala de destino e informe a temperatura que deseja converter.

---

## ✨ Funcionalidades

O sistema permite realizar as seguintes conversões:

- 🌡️ Celsius → Fahrenheit
- 🌡️ Celsius → Kelvin
- 🌡️ Fahrenheit → Celsius
- 🌡️ Fahrenheit → Kelvin
- 🌡️ Kelvin → Celsius
- 🌡️ Kelvin → Fahrenheit

Além disso, o sistema possui:

- 🌐 Interface web;
- 🔄 Conversão de temperaturas em tempo real após o envio do formulário;
- ❌ Validação de valores inválidos;
- ⚠️ Validação para impedir temperaturas negativas em Kelvin;
- 🔢 Aceitação de números com ponto ou vírgula;
- 📱 Interface adaptada para diferentes tamanhos de tela;
- 🎨 Design personalizado.
